# sliding 数字拼图

终端里的经典 15 数字拼图（滑动拼图）。WASD 移动空格，把打乱的数字复原成 1…n²-1。

纯标准库（argparse / random / secrets / sys），无需安装。

## 玩法

```bash
python -m sliding              # 4x4 交互开局
python -m sliding --size 3     # 3x3（8 拼图）
python -m sliding --shuffle 50 --seed 42
python -m sliding --auto wasd --seed 7   # 脚本化移动序列（验证用）
```

- 输入 `w/a/s/d` 移动空格（空格分别向 上/左/下/右 走），`q` 退出。
- 右上角计数器记录步数；复原后报喜。

## 为什么初始局面一定可解

初始局面不是随机打乱的，而是**从目标局面出发做 N 次随机合法移动**。
合法移动不改变拼图的可解性（可解性是移动的等价类），而目标局面本身可解，
所以任何由它移动得到的局面都可解——这是构造性保证，不需要事后验算。

## 设计取舍

- 打乱用“随机游走”而非“随机排列+判可解重试”：随机排列一半不可解，
  重试平均浪费一次生成；随机游走天然可解且均匀性对游戏足够好。
- `is_solvable()` 的逆序数奇偶性判据保留在代码里，用于验证游走的正确性。

## 已知局限

- 无悔棋（undo）；走错了只能自己走回来。
- 行输入模式：每步需回车确认，不支持方向键（需要终端 raw 模式）。
- 棋盘大小限制 2–9。
- 不记录最佳成绩。
